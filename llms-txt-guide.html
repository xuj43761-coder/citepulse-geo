Complete llms.txt Guide (2026): Specification, Examples & Deployment

Updated November 2026 • 5-minute read • Technical GEO Reference

What is llms.txt? It is a lightweight Markdown file hosted at /llms.txt that gives Large Language Models, AI coding assistants, and retrieval agents a clean, curated index of your most authoritative pages—without forcing them to parse navigation chrome, cookie banners, or client-side scripts.

Required llms.txt Markdown Structure

Following the widely adopted llmstxt.org convention, a valid llms.txt file contains five clean elements in order:

  1. Single H1 Title (# Brand Name) — Required first line identifying your product or documentation site.
  2. Summary Blockquote (> ...) — One concise sentence explaining what you offer and who you serve.
  3. Optional Context Paragraph — Key facts (pricing model, supported integrations, compliance standards) that prevent hallucinated product specs.
  4. H2 Section Headings (## Core Docs, ## Pricing & Security) — Logical grouping of your highest-signal pages.
  5. Absolute HTTPS Markdown Links — Formatted as - [Page Title](https://example.com/page): Short description of facts on this page.

Copy-Paste Example

# Acme Cloud

> Automated SOC 2 Type II and ISO 27001 compliance platform for B2B SaaS startups.

Acme Cloud connects to AWS, GitHub, and Okta in under 15 minutes with transparent annual pricing starting at $6,500/year.

## Core Pages
- [SOC 2 Automation Overview](https://acmecloud.example/soc2-automation): Scope, continuous control monitoring, and audit timeline.
- [Pricing & Plans](https://acmecloud.example/pricing): Exact plan tiers, seat limits, and auditor bundle options.
- [Security & Subprocessors](https://acmecloud.example/security): Encryption standards, data residency, and trust center links.

## Optional
- [XML Sitemap](https://acmecloud.example/sitemap.xml): Full list of public URLs.

Common Validation Mistakes to Avoid

  • Using relative links (/pricing): Always use full https:// URLs so agents reading raw text outside your origin can resolve pages unambiguously.
  • Dumping 500 blog URLs: That is what sitemap.xml is for. Keep llms.txt focused on your top 8–25 canonical product, pricing, documentation, and benchmark pages.
  • Blocking AI crawlers from reading it: Ensure your robots.txt does not disallow /llms.txt for search bots (check your policy here).

How to Deploy /llms.txt in 2 Minutes

Hosting Stack Where to Place llms.txt
GitHub Pages / Static HTML Drop llms.txt directly in the repository root (or docs/ publish folder).
Next.js / Vite / Astro / Vercel Place in public/llms.txt so it serves statically at /llms.txt.
Cloudflare Pages / Netlify Place in your static output directory (e.g., public/ or dist/).
WordPress Upload to your web root via SFTP/host file manager or enable via an SEO plugin's static file module.
Verify Whether AI Search Engines Cite Those Exact URLs: Once /llms.txt is live, track brand mentions and URL citations across ChatGPT, Perplexity, and Google AI Overviews with SE Ranking (SE Visible) or Otterly.AI.
